Git Cheat Sheet 2.0

Los comandos esenciales para dominar el control de versiones

Configuración

  • git config --global user.name "Tu Nombre" Define tu nombre de usuario global.
  • git config --global user.email "tu@email.com" Define tu correo electrónico global.
  • git config --list Muestra la configuración actual.

Iniciar Proyecto

  • git init Inicializa un nuevo repositorio Git en el directorio actual.
  • git clone <url> Clona un repositorio remoto a tu máquina local.

Trabajo Diario

  • git status Muestra el estado de los archivos (modificados, en staging, etc.).
  • git add <archivo> Agrega un archivo al área de preparación (staging). Usa . para todo.
  • git commit -m "mensaje" Guarda los cambios preparados con un mensaje descriptivo.
  • git log Muestra el historial de commits.

Ramas

  • git branch Lista las ramas locales.
  • git branch <nombre> Crea una nueva rama.
  • git checkout <nombre> Cambia a la rama especificada. (O usa 'git switch').
  • git merge <rama> Fuciona la rama especificada con la actual.

Sincronización

  • git fetch Descarga cambios del remoto pero no los fusiona.
  • git pull Descarga cambios y los fusiona (fetch + merge).
  • git push Sube tus commits locales al repositorio remoto.

Deshacer Cambios

  • git checkout -- <archivo> Descarta cambios en el directorio de trabajo.
  • git reset --soft HEAD~1 Deshace el último commit manteniendo cambios en staging.
